### 🌟 Featured Project: AI / RAG Application

#### 🔗 [Anonybook — AI-Powered Distributed Social Platform](https://github.com/maaz-azhar-9)
*A distributed social platform built with the MEAN Stack, Node.js microservices, OpenAI API, and Qdrant Vector Database*

- Architected a distributed, **AI-driven social platform** using **MEAN Stack** and decoupled **Node.js microservices** for fault isolation, independent scalability, and separation of concerns across multi-cloud environments.
- Built an advanced **semantic search engine** via a **RAG (Retrieval-Augmented Generation) pipeline** — posts embedded with OpenAI `text-embedding-3-large` (3072 dims), stored in **Qdrant Vector DB**, retrieved via cosine similarity for multilingual, context-aware search.
- Orchestrated **multi-cloud deployment**: Angular on Vercel, Node.js API on Render, AI microservice on Railway — secured via JWT authentication and environment-scoped secrets.
- Designed a **stateless, scalable backend** with Cloudinary CDN, feed pagination, and rate limiting engineered for high availability under concurrent load.
